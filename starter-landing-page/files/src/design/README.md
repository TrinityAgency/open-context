# src/design/

Generated by `pnpm design:sync` from `design/export/project`: `tokens.css`, `components.css` and `catalog.ts`.
Never edit these files by hand; change the design in Claude Design, re-export, and run `pnpm design:sync` again.
They carry a banner that says so.

The one hand-written file here is `no-hardcoded-colour.test.ts`: it fails when a colour literal appears in site
code outside this folder. A colour is written once, in the tokens; site code only names tokens.
`.gitkeep` keeps the folder in git before the first sync.
